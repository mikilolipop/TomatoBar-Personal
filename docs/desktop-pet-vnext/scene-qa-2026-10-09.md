# Tomy 七场景改版检查

2026-10-09。用户反馈：原生七状态只靠眨眼和微小姿态变化，动作过于一致，缺少场景。本轮已用不同活动场景替代，沿用已选番茄主体与紧凑窗口。Windows 未改。

## 当前表现

| 状态 | 活动与姿态 |
|---|---|
| 待机 | 站立、呼吸、眨眼 |
| 专注 | 抱着打开的书阅读，6.4 秒内点头并翻页 |
| 专注暂停 | 书合上、书签露出，静止等待 |
| 休息 | 闭眼、明显侧身，靠在小枕头上缓慢呼吸 |
| 休息暂停 | 仍有枕头，睁眼并坐直一些，静止等待 |
| 专注完成 | 一次约 8 点的小跃起，随后保留星星奖章 |
| 休息结束 | 醒来伸展一次，保留枕头与小太阳 |

身体只绘制同一个中性位图，眨眼仅覆盖原眼部矩形。新生成的是独立道具层，来源与实际提示词见 `scene-assets-v1.md`。身体姿态与道具约 0.34 秒平滑过渡；悬停不会重新触发完成动画。减少动态效果与关闭动画保留静态场景。两种暂停在过渡结束后释放动画 Timer。

## 本机验证

`scripts/dev-run.sh` 完整通过：263 领域 + 43 动画 + 89 桥接/原生处理器 + 8 合成启动检查，共 403 项。universal Release 构建与严格签名通过，随后从 `/tmp` 启动开发版。正式安装副本未替换。

绘制回归覆盖全部七状态，以及所有不同状态两两切换的五个过渡采样点。检测角色/道具是否超出实际 96 点窗口，并对照透明/不透明绘制像素与点击区域。旋转后奖章边缘的解析点击计算存在像素采样差异，已改为缓存实际合成绘制 alpha，覆盖道具、眼部、过渡与遮挡。

浏览器独立预览实查：七状态选择、状态对照、小尺寸、深色背景、减少动态效果。已修正窄窗口对照画布宽高不一致导致的纵向拉伸。页面不连接真实数据或计时器。

原生隔离 QA 使用独立进程 `Tomy Desktop QA` 和新建临时 FocusStore。实际检查了七状态对照渲染，分别切换真实 TBTimer 至专注、休息、专注暂停和专注完成，并读取真实浮窗 contentView 缓存图像；角色、道具、姿态与阶段相符，窗口仍为 96×96 点。正常退出该 QA 进程。
