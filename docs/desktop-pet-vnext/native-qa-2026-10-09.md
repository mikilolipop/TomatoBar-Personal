## 实现与视觉依据

原生 `CompactTomyAtlas` 使用 `pet_tomy_compact_v1` 的中性主体与两个独立眼部区域。七种状态共用轮廓、叶冠、嘴巴、四肢与光照，不切换整张角色。测试与预览均读取实际素材，未使用替代图形。默认角色高度 80 点、窗口 96×96 点，另提供 64/96 点角色高度。

原生隔离工具有独立进程名 `Tomy Desktop QA`、独立 bundle 标识与临时 FocusStore；不构造真实应用的 TBApp/TBStatusItem。通过 Computer Use 检查七种原生绘制，确认睁眼/闭眼姿态与已选母稿一致。休息计时状态和实际浮窗内容的缓存图也已检查，主体没有镜像、轮廓漂移或裁掉脚底。缓存图是原生窗口内容，不能作为桌面合成/跨窗口点击的证据。

本地截图：`qa-native-final.png`、`qa-native-state-strip.png`。截图遵守仓库惯例，不提交到 public 仓库。

## 待真人桌面验收

实现已经接入，以下桌面行为不能仅由当前窗口截图、处理器检查或合成几何测试宣布通过：

1. 将桌宠拖到普通窗口上，确认点击番茄控制计时、点击透明边角操作背后窗口；悬停气泡不会阻挡鼠标。
2. 双击只打开主面板，拖动释放不会误开始/暂停；右键菜单能更换尺寸、形象和隐藏。
3. 在屏幕四角、两个真实显示器、切换 Space/全屏和断开显示器时观察位置、裁切与气泡避让。
4. 隐藏再显示、重新启动、真实睡眠/唤醒；系统减少动态效果、VoiceOver 与长期资源占用。

当前 Computer Use 会单独捕获并操作主窗口，没有可靠的跨窗口桌面合成画面。验收中背后按钮计数变化不能证明透明穿透已经通过，已明确保留这项边界。未测真实多屏、Space、睡眠、VoiceOver，也没有声称 CPU/内存改善的量化结果。未制作新发布版本或替换 `/Applications` 安装包。
