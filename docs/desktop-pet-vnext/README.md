## 样片内容

`index.html` 是独立、无依赖的动作查看页。角色默认可见高度 80 CSS px；也可查看 64、96 px。预览中 CSS px 对应浏览器布局点，并非测得的物理屏幕像素。

- 七种状态切换与对照：待机、抱书阅读和翻页、靠枕睡觉、合书等待、休息暂停醒来、星星庆祝、睡醒伸展。侧身是二维姿态变化。
- **始终绘制同一张主体**，眨眼只覆盖两个既定眼部区域。叶片、身体、四肢、嘴巴、光照不随眨眼换整帧。
- 使用同一个时间轴驱动桌面尺寸与放大视图；身体姿态与道具同步，状态切换约 0.34 秒。
- 支持拖动、悬停状态、双击/按钮重播、方向键微调、深浅背景、停止动画及减少动态效果。
- 状态信息仅在悬停或键盘聚焦时显示。25:00 是示例，没有连接真实计时器或用户数据。
- 页面隐藏时取消动画调度。减少动态效果停止全部动画，保留场景和姿态。

首轮完整 8 帧素材的转向帧出现叶片与光照镜像，已拒收，未纳入本目录。不要恢复它。当前眨眼条只用于提取眼部区域，不能改回整帧切换。

## macOS 原生实现

- `PetMotion.swift` 提供同一单调时间轴驱动的七种状态：待机、专注、休息、专注暂停、休息暂停、专注完成、休息结束。姿态切换约 0.34 秒；完成动作播放一次后停播，悬停不重播。
- `CompactDesktopPet.swift` 固定绘制中性主体，只覆盖眼部裁片；身体与独立道具组合成不同活动场景，读书翻页、侧身靠枕和星星庆祝可直接区分。没有重新生成不同状态的身体。
- Tomy 默认可见高度 80 点，窗口 96×96 点；右键可选 64/80/96 点。常驻头牌、桌椅、耳机、笔记本和倒计时胶囊已从新版 Tomy 中移除。名称、真实状态和倒计时只在悬停气泡显示。
- 原生鼠标区域根据主体与道具的透明度和当前姿态计算，透明处切换窗口鼠标穿透；双击取消排队的单击，拖动不触发计时，释放后轻微回落。绘制视图本身不拦截设置按钮的点击。
- 隐藏、关闭动画、系统减少动态效果会停止动画计时；完成动作和两种静止暂停也释放动画计时器。隐藏及睡眠时停止鼠标监测，重新显示/唤醒后恢复。
- 保留其他三款角色与旧 Tomy 素材、计时域模型及存储格式。Windows 子工程、资源和工作流未改。

macOS 开发运行使用 `scripts/dev-run.sh`；原生隔离预览使用 `scripts/preview-desktop-pet.sh`（先构建）。浏览器的 `index.html` 已升级为**独立七场景样片**，没有真实计时数据。

当前场景验证见 `scene-qa-2026-10-09.md`；上一版原生交互边界见 `native-qa-2026-10-09.md`；先前浏览器证据仍见 `design-qa.md`。QA 截图只保存在本地。
