# Tomy 桌宠升级 · macOS 完整姿态动作

2026-10-09。用户要求同步到实际 App 后，专注、休息两段完整姿态已接入 macOS，并更新、启动本机 `/Applications/TomatoBar Personal.app`。独立浏览器样片 `http://127.0.0.1:8764/` 保留用于对照；Windows 不在本轮范围内。

## 形象与动作

保留用户选定的第 1 款圆润番茄方向：像素风、红绿配色、短小四肢、柔和立体色阶与左上光照。第一版的电脑操作与捧杯姿态作为动作关系参考。第 2、3 款形象不作为后续素材参考。

- 专注：真正坐下，电脑放在腿上，双手交替抬起/按键，脚伸向前方。连续敲键盘约六秒后眨眼。
- 休息：坐下双手捧杯，上举到嘴边喝一口，再放回。下放使用上举的中间姿态反向衔接，约四秒一轮。
- 每段各六个完整姿态帧；直接绘制新生成的完整角色帧。身体与手脚已重新设计，不使用旧站立主体叠加道具。
- 所有帧共用统一取景边界与显示比例，按叶冠定位抵消生成网格的平移差异；不逐帧放大，不用整张图旋转来表达坐姿。
- 新姿态是逐帧生成的动画草稿；位置校准消除主要平移差异，不等于每个叶片或纹理像素完全相同。

## 历史方案与原生边界

仅靠眨眼、微幅姿态区分七状态的方案，以及固定站立身体叠加书/枕头/星星的场景方案，均被用户否决。不能将对应检查通过当作视觉验收通过，也不能恢复为当前推荐方案。

被否决的场景页保留为 `scene-v1-rejected.html` + `scene-player.js`，只供对照。先前素材和 QA 记录保留，不改写历史证据。

## 原生接入

- 专注/休息加载各自六帧完整坐姿，PNG 与独立样片逐字节相同，原生取景与时间轴也逐项核对。
- 暂停冻结当前完整动作帧，继续从同一时间接着播。悬停、缩放不重启动作；拖动和减少动态效果冻结动画。
- 待机保留已选角色的眨眼。完成状态使用对应坐姿的静止帧，专注结束一次小幅抬身，休息结束一次小幅伸展，然后停止动画计时器；本轮没有额外生成专属完成精灵表。
- 跨姿态切换用 0.34 秒完整角色淡入淡出。点击范围随完整角色、电脑/杯子和过渡 alpha 更新，不再加载被否决的独立书、枕头、星星场景。
- 263 项领域 + 49 项动画 + 95 项真实桥接/原生处理器 + 8 项合成启动检查通过。实际独立原生窗口与浮窗内容已视觉检查。
- 本机安装副本与已签名 universal 构建的可执行文件、Assets.car 相同，唯一实际进程来自 `/Applications`。旧 App 与更新前后的记录快照保留在仓库外，安装前后 JSON 全部字段一致。

本轮为本机更新，版本元数据仍是 3.10.0/build 7，未制作公开发布包、标签或更新官网；新动作的最终观感仍由用户实际使用反馈判断。Windows 后续单独处理。
