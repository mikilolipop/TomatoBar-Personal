# TomatoBar Personal V1.3.2

发布日期：2026-10-01。内部版本 **3.9.2**，build **3**。

修复记录编辑器中点击「主分类」下拉箭头没有反应的问题。

## 更新内容

- 主分类名称与右侧箭头对应同一个完整点击区域，点击任一处都能展开菜单。
- 保留已有分类、建议分类、当前分类标记与原有配色；选择分类后更新编辑草稿及图标。
- 沿用已有记录、待办、分类样式和设置，存储格式及 Bundle ID 保持兼容。

## 下载与安装

前往 [V1.3.2 Release](https://github.com/mikilolipop/TomatoBar-Personal/releases/tag/v3.9.2)。

| 文件 | 用法 |
|---|---|
| `TomatoBarPersonal-3.9.2.dmg` | 打开后将应用拖到 Applications |
| `TomatoBarPersonal-3.9.2.zip` | 解压后将应用放入 Applications |

两个下载包均包含 **arm64 + x86_64**，要求 macOS 12.3 以上。
更新前正常退出 TomatoBar Personal，再替换安装目录中的同名应用。
公开包使用 ad-hoc 签名，未做公证；首次打开说明见 [README](../README.md#安装)。

## 验证

- 214 项领域、40 项真实 TBTimer 桥接、8 项合成启动事件检查通过。
- 双架构 Release 构建、版本元数据与严格签名校验通过。
- DMG 校验和、只读挂载、应用签名及 Applications 链接检查通过；ZIP 解压后的签名与可执行文件一致性检查通过。
- 主分类修复已在本机主窗口实测：鼠标点击箭头和名称均展开菜单，选择分类更新草稿，取消后保持原记录；原有记录、待办与分类样式快照逐条一致。

菜单栏编辑器复用相同控件，其独立入口未在本轮实测。Intel 未实机验收，8 项合成启动检查不代表真实登录/Dock/Space 验收。
