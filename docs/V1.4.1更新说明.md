# TomatoBar Personal V1.4.1

发布日期：2026-10-05。内部版本 **3.10.0**，build **7**。

本版本为重大体验重塑更新，引入 Bluebird 风格持续任务专注流、大任务/项目层级体系、待办面板视觉去拥挤与悬浮操作（Hover Actions）、大任务主标签自动继承与智能合并、自定义新标签、调色盘新增齿轮图标、跳过休息与菜单栏折叠面板。

---

## 🌟 核心更新亮点

### 1. 待办面板视觉去拥挤与 Hover Actions
- **黄金均衡分栏**：下半区左右分栏由原先局促的 `29% : 71%` 重塑为从容均衡的 `46% : 54%`（保证至少 380px，自适应可达 540px+），待办排版横向空间翻倍；
- **悬浮显现操作按钮（Hover Actions）**：子任务行采用 Apple 提醒事项 / Linear 风格的悬浮操作，平时隐藏 `▶` 与 `...`，鼠标悬浮时平滑高亮显现；任务标题与标签独占宽阔横向空间，**彻底告别名称截断**；
- **全局添加栏纯净全宽**：移除快速添加框左侧挤占空间的下拉选择器，还原整行纯粹输入，拆解子任务直接在大任务卡片内输入。

### 2. 大任务主标签专属支持与子任务自动继承
- **大任务主分类**：大任务卡片支持设置主标签（如 `#竞赛`、`#专业课`、`#科研`），并在卡片标题旁以彩色药丸徽标呈现；
- **子任务默认自动继承**：在大任务下新建子任务时，若未手动指定标签，自动继承该大任务的主标签；
- **细分标签智能前置合并**：若子任务输入了专属细分标签（如 `#机械`），系统自动智能拼合为 `[母项目主标签, 子任务标签]`（确保统计主分类自动归集到母项目类别下，同时保留子任务微观细分）；
- **任务迁移智能赋标**：当把散装无标签任务移入某大任务时，系统自动补全母项目的分类标签。

### 3. 图案调色盘新增「齿轮」图标
- **调色盘新增齿轮**：在分类/标签样式编辑器的图标下拉菜单中正式加入 **⚙️ 齿轮**（`gearshape`），适配机械、工程、调参、设备等工科场景；
- **默认语义映射**：标签名包含「机械」或「工程」时，默认自动映射为齿轮图标；
- **保持老数据散列稳定**：保留了内置 10 项 fallback 图标库未变，已有历史未自定义标签的默认图标完全不发生漂移。

### 4. 大任务与子任务层级管理（Bluebird 风格）
- **长周期目标规划**：新增大任务/项目模型（`FocusProject`），可用于建立长期学习或项目目标（如“Robomaster校内赛”、“材料力学大作业”）；
- **双向聚合与记录归属**：针对大任务下子任务专注时，时间精准记录在子任务上，同时向上自动汇总至大任务累计总时长（`🎯 X小时X分`）；
- **结构化分组**：菜单栏 Popover 的「选任务」与切换任务菜单均按大任务结构化分组呈现。

### 5. 自定义新标签与 `#标签` 快速解析
- **自由输入新标签**：标签菜单底部增加「+ 自定义新标签...」，彻底打破仅限内置标签的限制；
- **行内 `#标签` 极速解析**：在添加任务或专注事件时直接支持 `#标签` 语法（例如 `复习机械原理 #学习 #期中` 自动提取标题与标签）。

### 6. 跳过休息（Skip Rest）
- 专注完成浮动提醒窗、菜单栏 Popover 与主窗口在休息倒计时中均提供「跳过休息」；
- 跳过休息保留当前组内轮次与长休息节奏，保留绑定任务，且绝不把休息时间误记为专注时长。

### 7. 菜单栏 Popover 记录列表折叠
- 菜单栏弹窗下方的记录/时长面板默认紧凑折叠，支持一键展开/收起，并使用 `@AppStorage` 记忆折叠偏好。

## 📦 下载与安装

前往 [GitHub Releases](https://github.com/mikilolipop/TomatoBar-Personal/releases/tag/v3.10.0)。

| 文件 | 格式 | 用法 |
|---|---|---|
| `TomatoBarPersonal-3.10.0.dmg` | DMG 磁盘映像 | 打开后将应用拖到 Applications |
| `TomatoBarPersonal-3.10.0.zip` | ZIP 压缩包 | 解压后将应用放入 Applications |

两个下载包均包含 **arm64 + x86_64**（Universal 架构），要求 macOS 12.3 以上。
更新前正常退出 TomatoBar Personal，再替换安装目录中的同名应用。
公开包使用 ad-hoc 签名，未做公证；首次打开若遇拦截，在终端执行：
```sh
xattr -dr com.apple.quarantine "/Applications/TomatoBar Personal.app"
```
