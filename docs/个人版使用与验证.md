# TomatoBar Personal 3.7.0

安装位置：`/Applications/TomatoBar Personal.app`
源码分支：`feature/personal-focus`

## 已实现

- 开始前填写事件名称；空白名称保存为“未命名专注”。
- 完成或提前结束后保存实际专注时长，分别显示“已完成”和“提前结束”。暂停、休息和等待确认不计入专注时长。
- 工作和休息都支持暂停/继续；菜单栏用 Ⅱ 标记暂停。
- 记录页显示历史事件、日期、开始时间和实际时长；今日时长按每段专注与本地日历日期的交集累计。
- 移除声音播放代码、声音设置和三个音频素材。
- 工作或休息结束后显示无声的置顶提醒窗口，等待确认才开始下一段；菜单栏同时显示“请确认”。无需系统通知授权。
- 电脑睡眠或正常退出时自动暂停。运行中每 5 秒保存检查点，异常中断恢复时暂停在最近检查点，最多可能少记约 5 秒；离线时间不计入专注。
- 使用 Application Support 下的 `TomatoBarPersonal/sessions.json` 原子保存状态与历史；界面“打开记录文件夹”可以访问。
- 文件损坏时保留原文件并阻止新计时；写入失败时显示错误，退出前检查未保存状态。

## 与原版共存

个人版使用独立标识符 `com.dilyar.TomatoBarPersonal`，原版应用、偏好和缓存未迁移或覆盖。两者可以同时运行；使用个人版时可手动退出原版，避免两个菜单栏图标混淆。登录启动开关沿用原项目组件，默认不替用户启用。

快捷键作用为开始 / 暂停 / 继续；等候确认时打开提醒。个人版 URL 为 `tomatobar-personal://startStop`。
