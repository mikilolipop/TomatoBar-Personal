# TomatoBar Personal V1.4

发布日期：2026-10-05。内部版本 **3.10.0**，build **5**。

引入 Bluebird 风格持续任务专注流、大任务/项目与子任务层级管理、自定义新标签、跳过休息、输入前选标签与菜单栏折叠面板。

## 更新内容

1. **大任务与子任务层级管理（Project & Subtask Hierarchy，Bluebird / 提醒事项风格）**：
   - 新增大任务/项目模型（`FocusProject`），可用于建立长期学习或工作目标（如“Robomaster校内赛”、“材料力学大作业”）；
   - 主窗口待办面板重构为「大任务折叠卡片 + 子任务列表 + 独立待办/收集箱」体系；
   - 每个大任务卡片醒目呈现子任务完成比例（如 `2/5`）与大任务累计专注投入总时长（如 `🎯 2小时15分`）；
   - 支持在大任务卡片内行内快速添加子任务、任务所属大任务迁移及大任务归档/重命名/安全解绑删除；
   - 菜单栏 Popover 的「选任务」与切换任务菜单均按大任务结构化分组呈现，并标明大任务上下文。

2. **自定义新标签（Custom Tag Entry）**：
   - 彻底打破以往只能选用已有标签或系统内置建议的限制；
   - 待办标签菜单、自由专注草稿标签菜单底部均提供「+ 自定义新标签...」；
   - 输入新标签后即刻生效，自动完成标准化处理并无缝沉淀至 `knownTags` 已有标签池。

3. **双向时间聚合与记录归属**：
   - 当针对某个大任务下的子任务进行专注时，时间精准记录在该子任务上，同时向上自动汇总至大任务；
   - 专注卡片与专注记录自动标注 `🎯 [大项目] · 子任务`，兼顾宏观投入与微观明细。

4. **跳过休息（Skip Rest）**：
   - 专注完成浮动提醒窗新增「跳过休息」按钮，点击直接进入「准备下一轮」状态；
   - 菜单栏 Popover 与主窗口在休息倒计时中提供「跳过休息」与「结束本组」；
   - 跳过休息保留当前轮数 `rounds` 与长休息周期，保留绑定任务，不将休息记入专注时长。

5. **输入任务前选标签与 `#标签` 快速解析**：
   - 输入待办或专注事件时支持行内 `#标签` 语法（例如：`复习机械原理 #学习 #期中` 会自动拆分标题与标签）；
   - 自由专注输入框旁增加标签选择 Pill，支持已有标签与建议分类一键选择；
   - 待办列表支持显示标签徽标，更多菜单中支持快捷修改标签。

6. **菜单栏 Popover 记录列表折叠**：
   - 菜单栏弹窗下方的记录/时长/设置面板默认折叠，大幅降低纵向空间占用；
   - 点击 Tab 标签或右侧 Chevron 箭头可平滑展开/折叠，并使用 `@AppStorage` 记忆折叠偏好；
   - 编辑单条记录时自动展开，保障编辑体验完整。

7. **Bluebird 风格持续专注任务流**：
   - 支持选定目标任务，并在多轮番茄钟之间粘性持续，无需每轮重新指定；
   - 准备阶段提供醒目的「🎯 当前任务」卡片，显示当前任务标题、母项目、标签及累计已专注时长；
   - 支持随时切换其他待办，或点击 `✕` 一键切回自由专注；
   - 勾选完成任务或删除任务时自动解绑，不影响正在运行的专注记录归属。
