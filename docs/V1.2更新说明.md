# TomatoBar Personal V1.2

原生 macOS 主窗口，用来回顾已经做过的事情。内部应用版本为 3.8.0。

## 使用

- 打开应用，或从菜单栏点击“打开主窗口”。关闭主窗口后，计时继续；退出应用则自动暂停。
- “概览”可切换日、周、月。箭头翻页，“回到今天”回到当前周期。
- 日视图每个色块代表一段专注，按开始时间排列；很多记录会换行并滚动。悬停查看具体名称和时长，点击编辑。
- 周视图显示七天的分类堆叠柱，点击一天进入日视图。
- 月视图按当天累计专注时长显示色深，点击日期进入日视图。未来日期不可选。
- 左侧先显示用时最多的五个分类，可展开其余分类，也可点击筛选；再次点击或点记录标题旁的清除按钮恢复全部。
- 历史页支持名称与标签搜索，包含所有标签，不仅是统计分类。
- 记录的第一个标签用于统计分类，其他标签用于搜索和筛选。编辑器中可以改变统计分类。每段时长只计算一次。
- 底部计时卡与菜单栏共用同一个计时器。右侧展开按钮进入大倒计时，可暂停、继续、结束并记录。
- 设置中可以关闭轻微像素动画。系统“减少动态效果”、暂停、窗口失焦、最小化或关闭时停止装饰动画。

## 统计口径

总计仅包括已经结束的专注记录，也包括提前结束时实际专注的部分；进行中的专注、暂停、休息不计入。跨午夜的记录按实际片段分配到对应日期。周从周一开始；月份和夏令时使用系统日历边界。

总计取整显示到分钟；不足一分钟显示秒。完整秒数仍保存在原记录中。色块宽度设有最小点击宽度和最大宽度，适合回顾顺序，不是严格按面积读数的图表。

## 数据和版本范围

继续使用原来的本地 sessions.json，没有改写旧记录的 ID、时长和完成状态。本次不包含云同步、待办计划或 iPhone / iPad / Watch 端。
