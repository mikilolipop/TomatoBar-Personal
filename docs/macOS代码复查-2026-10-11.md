## 问题与证据

### P29 · 中等 / P2：移动子任务后，历史时长同时计入两个大任务

**状态：已运行复现，未修复。**

`TomatoBar/State.swift:443-450` 同时按记录里的 `projectID` 和任务当前所属项目匹配。新记录在 `State.swift:700-703` 保存项目归属；随后通过主窗口的“移至大任务”（`MainWindow.swift:1398-1408`）移动任务，只改变任务的 `projectID`。

复现：在 A 下的子任务完成 60 秒专注，再把该任务移动到 B。实际记录仍是 60 秒，但 `focusSeconds(forProject:)` 返回 A=60、B=60，两个项目合计 120 秒。此时记录中的历史归属 A 和任务当前归属 B 都被当成有效条件。

建议：有记录级 `projectID` 时以其历史归属为准；只对缺少该字段的旧记录使用任务归属回退。加入“完成后移动”“完成后解除项目关联”“旧记录无项目字段”的回归检查，保留旧数据兼容性。

### P31 · 中等 / P2：旧桌宠没有遵循系统“减少动态效果”

**状态：已静态确认遗漏；未切换系统偏好或进行实际窗口验收。**

`CompactDesktopPet.swift:203,233-235,239-242` 为 Tomy 读取系统偏好并监听变化；其他形象由 `DesktopPetView` 绘制（`CompactDesktopPet.swift:186-191`）。旧视图的动画入口 `DesktopPet.swift:545-555` 和下一帧调度 `:580-593` 只检查应用动画开关与显示状态，未读取系统减少动态效果设置。悬停也直接使用 spring 动画（`:499-502`）。

例如选择植小芽，应用“轻柔动画”打开，即使系统要求减少动态效果，旧路径仍会调度循环帧。这是不同形象之间的行为遗漏；当前 Tomy 路径已经处理此偏好。

建议：共用动画策略，至少统一应用开关、系统减少动态效果、可见性与睡眠状态。再用隔离原生实例检查：系统设置开/关、切换形象、隐藏/显示、睡眠/唤醒。源码检查不能代替这组实际验收。

### P30 · 低 / P3：分类筛选与聚合使用不同的名称等价规则

**状态：已运行复现，未修复。**

`State.swift:61,298-300` 和 `Analytics.swift:51` 通过 `caseInsensitiveCompare` 去重或筛选；`Analytics.swift:71` 却用 `lowercased()` 作为聚合键。这两种规则对部分 Unicode 名称不等价。

有效 JSON 里各有一条 `Straße`（60 秒）和 `STRASSE`（120 秒）记录时，解码后的已有主分类只有 1 个，统计却有 2 行（120/60 秒）。选择其中任一名称，筛选总计都会变成 180 秒，与该行显示的时长不一致。普通中文和 ASCII 大小写通常不触发；新建专注已有规范名称复用，因此主要影响旧数据/文件交换中的别名组合。

建议：分类选择、过滤和聚合共用名称等价规则，同时保留显示名称与当前 JSON 格式。历史 P12 修复的是图标样式键，这里的聚合问题仍存在。

## 可以简化的代码

### 1. 优先恢复计时与统计的刷新隔离，并减少重复统计

当前 `MainWindow.swift:7` 为 `@ObservedObject var timer`，同时观察 history；`:33-34` 的 summary/filtered 是即时计算属性。日期标题、导航按钮、分类列表、图表等多处反复访问这些属性（例如 `:233-234,265,272,285-289`），每次访问都会构造包含逐日汇总的 `FocusSummary`。

真实 TBTimer 的隔离探针在约 2.2 秒运行计时期间观察到 **timer 发布 4 次，history 发布 0 次**。因此主窗口父视图会接收纯倒计时更新，旧 BACKLOG P5 的“父视图只观察 history，不受 tick 影响”已经不符合当前源码。SwiftUI 可以合并通知，这个计数不等于实际 body 求值次数；本轮没有测整页帧耗时，不声称已复现卡顿或固定重算次数。

建议：将统计区域抽为独立视图，由 history、周期、日期、分类和样式变化驱动；计时卡片、任务区域各自观察需要的状态。一次统计快照复用汇总结果。若引入缓存，键要包含记录内容/版本和样式变化，不能只用 `records.count`，否则编辑同一条记录会留下旧结果。

### 2. 删除无调用的任务准备路径，保留不同生命周期的真实任务关联

全仓库 Swift 搜索 `prepareTodo(` 只找到 `Timer.swift:137` 的定义，没有生产或测试调用；`preparedTodoID` 唯一非 nil 赋值就在该方法。当前入口均调用 `selectCurrentTodo`，但旧字段仍在启动、改名、项目移动、完成、删除、重读及两个视图的当前任务判断中分叉。

建议：移除 `prepareTodo` / `preparedTodoID`，让当前选择统一走已持久化的 `currentTodoID`。`activeTodoID` 与 `seriesTodoID` 分别承担正在计时的记录归属和多轮延续，仍有独立语义，应保留并验证切换/完成/删除任务的行为。

### 3. 抽出重复的任务、标签菜单与显示名称格式

`View.swift` 与 `MainWindow.swift` 分别实现任务选择、已有/推荐标签选择和标签移除，例如 `View.swift:536-549` 与 `MainWindow.swift:1028-1041` 的比较/切换代码基本相同。`Timer.swift:129,158,190,214` 又重复生成项目前缀与任务名。

建议：先抽取小型共用菜单内容、标签切换函数和任务显示名函数。不同窗口的布局仍分别维护，避免把两套页面塞入一个充满条件的组件。

```sh
review_tmp=$(mktemp -d -t tomatobar-mac-stats-review)
trap 'rm -rf "$review_tmp"' EXIT
cat > "$review_tmp/main.swift" <<'SWIFT'
import Foundation
let now = Date(timeIntervalSince1970: 1_800_000_000)
var state = FocusState()
let a = state.addProject(name: "QA PROJECT A", at: now)!
let b = state.addProject(name: "QA PROJECT B", at: now)!
let todo = state.addTodo(title: "QA TASK", projectID: a, at: now)!
state.startWork(name: "QA FOCUS", seconds: 60, todoID: todo, at: now)
state.tick(at: now.addingTimeInterval(60))
state.setTodoProject(todoID: todo, projectID: b)
let actual = state.records.reduce(0) { $0 + $1.seconds }
print("project: A=\(state.focusSeconds(forProject: a)) B=\(state.focusSeconds(forProject: b)) actual=\(actual)")

func record(_ tag: String, _ seconds: Double) -> FocusRecord {
    let end = now.addingTimeInterval(seconds)
    return FocusRecord(id: UUID(), name: "QA CATEGORY", startedAt: now, endedAt: end,
        plannedSeconds: seconds, completed: true,
        segments: [FocusSegment(start: now, end: end)], tags: [tag])
}
let data = try JSONEncoder().encode([record("Straße", 60), record("STRASSE", 120)])
let records = try JSONDecoder().decode([FocusRecord].self, from: data)
state.records = records
var calendar = Calendar(identifier: .gregorian)
calendar.timeZone = TimeZone(secondsFromGMT: 0)!
let summary = FocusSummary(records: records, period: .day, date: now, calendar: calendar)
let selected = FocusSummary(records: records, period: .day, date: now, category: "Straße", calendar: calendar)
print("category: names=\(state.allCategories.count) rows=\(summary.categories.count) selected=\(selected.seconds)")
SWIFT
xcrun swiftc TomatoBar/State.swift TomatoBar/Analytics.swift "$review_tmp/main.swift" -o "$review_tmp/probe"
"$review_tmp/probe"
```
