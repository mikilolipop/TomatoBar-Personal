# TomatoBar Personal V1.5.0

发布日期：2026-11-18。内部版本 **3.11.0**，build **8**。

本版本全面重塑 macOS 桌面伴侣体验，移除旧版四宠混合实现，打造单宠极致版 **「番茄仔 Tomy」`@2x` Retina 原生微交互引擎**，并同步完成一轮全链路代码审查与能耗、交互边界修复。

---

## 🌟 核心更新亮点

### 1. 番茄仔 Tomy `8×9` `@2x` Retina 精灵图集（72 帧完整重建）
- **零裁边 `@2x` 清晰画质**：采用 `1536×1872`（`@2x`，单格 `192×208`）与 `768×936`（`@1x`）双倍率图集，全落地姿态严格锚定同一脚底基线（`feet_y1` 跨度 `0px`），消除换状态漂移、轮廓缺口与跨帧残影。
- **9 组 8 帧平滑动作**：
  - `Idle`：8 帧接地呼吸 + 90° 相位滞后叶冠摆动 + 3 段自然眨眼（半眨/全眨/半眨）与偶发双眨。
  - `Work`：6 相硬边敲击（去虚影）+ 屏幕蓝光脉动 + 轻点头 + 自然眨眼；专注冲刺期自动提速。
  - `Paused`：8 帧睡眠呼吸 + 错落飘升淡出的 `zZz`。
  - `Rest`：连续卷曲升腾热气 + 5 段抬杯、闭眼微笑轻抿、放下过渡。
  - `Celebrate`：蓄力压扁 → 伸展起跳 → 星光滞空 → 落地压扁回弹。
  - `Wave`：绕肩轴顺滑挥臂并锁定稳定 `:D` 开心笑脸。
  - `Drag`：8 帧凌空交替踢腿 + 叶冠轴心钟摆倾斜物理（`±10.5°`，松手 60fps 阻尼回正与重力压扁回弹）。
  - `Sad`：放弃专注时触发叶冠低垂 + 泪光闪烁轻颤。
  - `React`（新增第 9 行）：支持空闲半眨/全眨、四向光标眼神跟随与悬停微惊叹小跳。

### 2. 自然微交互、零空闲轮询与 Dock 磁吸停靠
- **四向眼神跟随 & Hover Perk**：待机且未锁定时热区延展至 `175pt` 环形区域，番茄仔会随光标方向看向左上 / 右上 / 左 / 右并保持轻微呼吸；首次鼠标悬停不透明像素时触发惊喜小跳招手（内置 `12.0s` 冷却防打扰）。
- **O(1) 像素穿透 & Auto-Ghost 自动避让**：预烘焙 `24×26` 透明穿透掩码，仅不透明区域响应悬停与点击；开启「锁定位置并穿透」后自动放行鼠标点击，光标靠近 `28%` 半透明自动让位，按住 `⌥ Option` 随时临时解锁拖动。
- **零轮询能耗架构**：以单次精确延时定时器取代持续高频轮询，结合全遮挡（`didChangeOcclusionStateNotification`）、显示器熄屏（`screensDidSleepNotification`）、系统睡眠与 macOS Timer Coalescing 容差收敛，隐藏或遮挡时 `0` 唤醒；完整兼容系统 **减弱动态效果（Reduce Motion）**。
- **防误触与置顶提醒联动**：常规/专注状态单击仅触发挥手动画（双击打开主面板）；专注或休息结束待确认态悬停胶囊提示「点我进入休息 / 点我开启下一轮」，单击番茄仔或从右键菜单确认时直接进入下一阶段，并自动关闭屏幕中央的 `TBReminder` 置顶提醒窗（磁盘保存异常时保留提醒以供重试）。

### 3. 本轮代码审查与边界修复
- **桌宠右键放弃专注恢复运行态**：弹窗前记录原本暂停状态，点「继续专注」或按回车安全默认恢复原先运行中的计时，不再被静态留在暂停态。
- **状态栏锚点与设置同步收敛**：菜单栏倒计时末尾锚定辅助窗口消除流苏重排时 Popover 左右跳动；按 `(show, size, locked, animations)` 差量过滤 `UserDefaults` 通知，消除输入任务名与拖拽写坐标导致的重复重排；菜单栏 Popover 与主设置同步提供尺寸调节（`64/80/96pt`）、锁定穿透与一键贴回右下角复位。

## 📦 下载与安装

前往 [GitHub Releases](https://github.com/mikilolipop/TomatoBar-Personal/releases/tag/v3.11.0)。

| 文件 | 格式 | 用法 |
|---|---|---|
| `TomatoBarPersonal-3.11.0.dmg` | DMG 磁盘映像 | 打开后将 `TomatoBar Personal.app` 拖入 Applications |
| `TomatoBarPersonal-3.11.0.zip` | ZIP 压缩包 | 解压后将 `TomatoBar Personal.app` 放入 Applications |

两个下载包均包含 **arm64 + x86_64**（Universal 架构），要求 macOS 12.3 以上；使用 ad-hoc 签名，未做付费公证。更新前先正常退出旧版，再替换 Applications 中的同名应用；首次打开若遇 Gatekeeper 拦截，在终端执行：

```sh
xattr -dr com.apple.quarantine "/Applications/TomatoBar Personal.app"
```
