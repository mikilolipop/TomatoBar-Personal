# TomatoBar Personal V1.3.1

发布日期：2026-10-01。内部版本 **3.9.1**，build **2**。

本版汇总 V1.3 发布后的待办、分类配色、计时和存储修复，以及本轮通过 Computer Use 实机检查的 UI 精修。
设置页从应用元数据读取实际版本号，避免安装副本与开发构建都显示旧标签。

## 更新内容

- 待办清单：添加、重命名、完成、排序，以及带入或直接开始下一段专注。
- 分类样式：可调整分类图标和颜色，主分类负责统计归属，其他标签负责搜索与筛选。
- 时长可直接输入数字，专注/短休息/长休息/每组四行输入框对齐。
- 日概览随窗口分配卡片空间，色块不再裁掉第二行；月历为实际行数预留空间，六行月份不再覆盖记录区。
- 概览记录名称与时间/标签分为两行，改善小窗口的可读性。
- 待办播放、勾选、更多、编辑、日期切换和展开图标统一比例与点击区域。
- 主窗口与菜单栏记录编辑器统一配色和分类下拉样式；菜单栏编辑时留出完整表单空间。
- 展开计时按钮和无声完成提醒使用当前界面配色；搜索无结果时提示调整关键词或筛选。
- 运行中的专注可以取消；取消确认期间冻结计时，安全返回恢复原先暂停状态。
- 包含近期存储重试退避、结束时落盘、同一记录编辑冲突、跨窗口筛选及计时边界修复。

本地记录格式及 Bundle ID 保持兼容，安装更新后沿用已有记录、待办和设置。

## 下载与安装

前往 [V1.3.1 Release](https://github.com/mikilolipop/TomatoBar-Personal/releases/tag/v3.9.1)。

| 文件 | 用法 |
|---|---|
| `TomatoBarPersonal-3.9.1.dmg` | 打开后将应用拖到 Applications |
| `TomatoBarPersonal-3.9.1.zip` | 解压后将应用放入 Applications |

两个下载包均包含 **arm64 + x86_64**，要求 macOS 12.3 以上。本机 Apple Silicon 已实际启动验收，Intel 未实机验收。
公开下载包使用 ad-hoc 签名，未做公证；本机正式安装保留项目的 Automatic Personal Team 开发签名。

更新前正常退出正在运行的 TomatoBar Personal，再替换安装目录中的同名应用。
源码构建使用 `scripts/build.sh`，默认生成双架构 Release 并校验签名。

## 验证

- 214 项领域检查、40 项真实 TBTimer 桥接检查、8 项合成启动事件检查通过。
- 双架构 Release 构建及严格签名校验通过。
- DMG 校验和、只读挂载、应用签名及 Applications 链接检查通过；ZIP 解压后的应用签名和可执行文件核对通过。
- 正式安装后的运行路径、设置页版本号和历史展示已检查；安装前后已有记录、待办与分类样式逐项一致。
- UI 检查步骤与边界见 [2026-09-30 UI 精细化检查](UI精细化检查-2026-09-30.md)。

8 项启动检查是合成事件，不能代替真实登录/Dock/Space 验收。原生确认框与菜单的截图受限，
