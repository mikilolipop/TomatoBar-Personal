# TomatoBar 项目理解与改进起点

核查日期：2026-09-27
上游：https://github.com/ivoronin/TomatoBar
源码基线：90a77d6（main）；发布页当前 Latest：v3.6.1。

## 产品与代码

轻量 macOS 菜单栏番茄钟，使用 SwiftUI 显示弹出面板、AppKit 管理菜单栏，通过 SwiftState 实现 idle / work / rest 三种状态。代码采用 MIT 许可证；README 单独说明声音素材的授权来源，后续分发需保留并核对相关授权。

- App.swift：应用入口、菜单栏图标和弹出面板。
- Timer.swift / State.swift：工作、短休息、长休息及轮次转换，按绝对结束时间计时。
- View.swift：计时入口、时长、设置和声音面板。
- Notifications.swift：系统通知及跳过休息动作。
- Player.swift：开始、结束与滴答声音及音量。
- Log.swift：在缓存目录写入 JSON 状态转换日志。
- 依赖：SwiftState、KeyboardShortcuts、LaunchAtLogin。

已具备：工作与休息时长设置、每组轮次、休息后停止、菜单栏倒计时、全局启停快捷键、登录启动、声音调节、简体中文、tomatobar://startStop。

## 从源码确认的功能边界

1. 没有暂停状态；停止会清空当前连续轮次，再开始会重新计时。
2. 没有内置历史统计页面；现有缓存日志不等于稳定的专注记录数据库。
3. 没有任务名称、项目分类等数据模型。
4. 没有退出后恢复计时状态的持久化实现。
5. 睡眠跨过结束时间超过默认 60 秒时，会停止计时；该行为是否适合用户需要讨论。
6. 工作、短休息、长休息的界面输入上限均为 60 分钟。

以上是功能边界，不代表这些功能都应加入。优先保留菜单栏使用的简洁感，按用户实际痛点选第一轮范围。

## 值得验证的代码问题

- updateTimeLeft 无条件使用隐式解包的 finishTime；首次开始前切换菜单栏倒计时设置可能触发空值问题，尚未做运行复现。
- 通知动作回调未调用 completion handler，且状态修改未显式切回主线程，应在处理通知相关改动时验证。
- 当前仓库未发现自动化测试 target；计时状态变更应补充针对行为的验证。
