# USER_FEEDBACK.md

公开仓库中的匿名用户反馈与产品决策记录。

## 隐私与记录规则

- 本仓库是公开项目。只记录产品需求、可复现行为和产品决策。
- 不记录反馈者姓名、账号、联系方式、个人习惯、健康/生活信息或其他可识别背景。
- 用户原话如包含个人信息，进入本文件前必须改写为匿名、最小必要描述。
- 单个用户提出的偏好不自动成为默认行为：先判断是核心产品问题、可配置偏好，还是仅作为彩蛋/实验保留。

---

## F001 — 当日累计专注使用人类可读单位

- 日期：2026-09-30
- 来源：匿名用户反馈
- 类型：信息可读性 / 核心显示规则
- 反馈：累计专注时间若始终用秒显示，几分钟后数字会过大，不利于快速理解。
- 产品决策：接受，作为所有用户统一行为，不做设置项。
- 显示规则：不足 1 分钟显示秒；1–59 分钟显示分钟；达到 1 小时后显示“X小时Y分”。
- 当前状态：现有 `focusDuration()` 已实现该规则；若用户仍看到纯秒数，优先确认是否运行了旧构建。

## F002 — Rest 状态的 🚬 隐藏彩蛋

- 日期：2026-09-30
- 来源：匿名用户反馈
- 类型：隐藏彩蛋 / 个性化视觉
- 需求：允许将菜单栏 `rest` 状态图标替换为直白的 `🚬` emoji 风格表达。
- 产品决策：接受为隐藏彩蛋；默认关闭，不作为公开设置项，不改变默认 rest 图标。
- 触发方式：在“设置”页连续点击版本号 `Personal · V1.3` 7 次切换开启/关闭；点击间隔超过 2 秒会重新计数。
- 反馈提示：切换成功时只显示一次轻量提示：“🚬 休息彩蛋已开启”或“休息彩蛋已关闭”，约 2 秒后自动消失。
- 实现：使用独立的 `@AppStorage("smokeBreakEasterEgg")` 保存；只改变 rest 状态的菜单栏视觉，不改变计时、休息时长、记录、通知等业务逻辑。
- 当前状态：2026-09-30 已实现，待 macOS 实机检查 emoji 的基线、尺寸和浅/深色菜单栏表现。
- QA：实际使用 emoji 字形时需在浅色/深色菜单栏下检查基线、尺寸和间距，避免彩色 emoji 与现有 template icon 的对齐不一致。
