# V1.1：记录改名与标签

应用内部版本：3.7.1。安装位置：`/Applications/TomatoBar Personal.app`。

## 使用

1. 打开菜单栏番茄钟，切换到“记录”。
2. 点击记录右侧的铅笔，修改事件名称。
3. 输入新标签后点击“添加”，或从“选择已有标签”中复用；一条记录可带多个标签。标签右侧 × 只移除该记录上的标签。
4. 点击“保存”。未点“添加”的标签输入也会一起保存；“取消”放弃本次编辑。
5. 使用记录列表上方“全部记录”菜单按标签筛选。

改名和标签不会修改原有 ID、计时时段、专注时长或完成状态。空事件名不能保存；标签会去掉首尾空白及大小写重复项。

## 数据兼容与回退

原有记录兼容读取，默认没有标签。首次加载旧格式时，在记录文件夹保存 `sessions.pre-v1.1.json` 原始副本，后续不覆盖该副本。

旧版应用备份：`~/Library/Application Support/TomatoBarBuildBackups/TomatoBar Personal-v1.0.app`。新版记录增加 tags 字段，原版读取时会忽略，但用旧版继续保存可能丢弃标签，因此回退前应另行备份当前数据。
