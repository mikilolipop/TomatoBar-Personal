# Windows 客户端重构 · 2026-10-11

用户要求集中改善 Windows，并对整个 Windows 工程进行代码重构。基线工作区干净，macOS 领域263项、原 Windows 7项与前端构建通过；原前端 lint 有4条警告。

## 修复与分层

原版 `App.tsx` 同时负责计时、持久化、设置和提醒，界面先改、保存错误只写日志。读取损坏会返回默认空状态后自动保存；恢复在当前时间暂停会计入离线间隔；取消和提前结束调用相同处理器；早于60秒的记录丢弃，标签项目关联未完整实现。

现在统一到 `FocusController` 的单写入队列，领域变更接受显式时钟，存储和桌面API由独立适配器提供。删除没有入口的重复组件及模板资源，记录编辑、任务行、导航、原生dialog与图表只有一套实现。TypeScript启用strict，前端检查以零警告为闸门，Rust依赖锁文件纳入仓库。

| 主题 | 最终行为 |
| --- | --- |
| 时间 | 片段计时、deadline封顶、不提前半秒完成；恢复停在checkpoint；脉冲大间隔暂停 |
| 数据 | 原生异步原子写入；损坏阻断；保存失败冻结并可重试；记录先落盘后显示 |
| 导入导出 | 严格校验，不伪造ID/日期；识别旧Windows和Swift日期；替换前单独备份；运行中不允许替换 |
| 设置 | 时长、长休息周期、宠物种类与显示均持久化；当前阶段时长不受修改影响 |
| 任务 | 大任务下添加子任务，继承标签；完成记录带任务/项目ID；不在工作中切换目标 |
| 展示 | 原生标题栏；日片段、周分类堆叠、月热力；统一可聚焦dialog；窗口内宠物拖动与减少动态支持 |
| 桌面 | 单实例；托盘；关闭主窗隐藏；退出先保存；到时无声置顶并在关闭提醒后解除 |

## Windows 实机验收

以下尚未在 Windows 电脑上操作，不得用Mac编译或浏览器检查代替：

- [ ] 安装NSIS/MSI、升级旧版本、启动新版本，并确认旧WebView记录迁移及原稿保留。
- [ ] 重复启动只出现一份主进程；托盘左键打开、右键各动作正确。
- [ ] 关闭主窗、后台运行超过一分钟后，计时和记录继续准确。
- [ ] 真实睡眠/唤醒恢复为暂停，不计入睡眠时间；时钟向后调整不会多算。
- [ ] 无声提醒从隐藏/最小化状态显示、置顶，关闭提醒后解除置顶。
- [ ] 退出计时保存为暂停；模拟磁盘只读/空间不足时不退出或丢弃未保存状态。
- [ ] 100%/125%/150%/200%DPI、多屏拖动、键盘焦点、Narrator和减少动态效果。

宠物仍是窗口内挂件，尚未实现独立跨应用桌面窗口。没有更换已安装macOS App、操作真实计时数据或发布新release。

npm run check

cargo test --manifest-path src-tauri/Cargo.toml --locked
cargo clippy --manifest-path src-tauri/Cargo.toml --locked --all-targets -- -D warnings
npm run test:interop # Mac + Xcode命令行工具
