# TomatoBar Personal V1.3

原生 macOS 主窗口 + 删除记录 + 分类入口。内部应用版本为 **3.9.0**。

## 本版新增

### 删除历史记录

- 每条记录都可以单独删除。主窗口记录行右侧的 **「⋯」** → 删除记录；
  编辑器（主窗口、菜单栏、点击今日色块进入的三处是同一个编辑器）左下角也有红色的 **「删除记录」**。
- 删除前会弹出确认，显示这条记录的**名称、日期、专注时长**，并说明「删除后，这段专注时长将从统计中移除」。
  默认按钮是**取消**，按 Esc 取消，按 Return 不会误删。
- 删除只影响统计和历史，不影响正在进行或暂停中的计时、轮次和休息安排。

### 统计分类：怎么分、长什么样，一目了然

之前只有当一条记录有两个以上标签时，才能看到「统计分类」的选择入口，
而且分类的图标和颜色是按名字写死的规则，用户无法知道。现在：

- 编辑器里**始终显示「统计分类」**，一条记录还没有分类时显示「未分类」。
- 分类选择器提供三类来源：**已使用的分类和标签**、**建议分类**（材料力学、建模、英语、
  编程、阅读、数学、写作，仅供快捷选择，不会自动创建任何示例记录），
  以及**自定义分类**输入框。
- 「统计分类」和「其他标签」**分成两块**，并写明了规则：
  **统计分类决定图表归属和图标；其他标签用于搜索和筛选。**
- 移除某个「其他标签」**永远不会**悄悄改变这条记录算在哪个分类下——
  统计分类只能从它自己的选择器里换。
- 选分类时可以实时看到该分类在**今日色块**上的图标和颜色效果。

### 分类图标：可以手动选

- 每个分类的图标除了按名字自动分配外，现在可以在编辑器里**手动指定**（调色板按钮，
  16 个候选图标，随时可以「恢复自动」）。这个设置跟着分类走，改一次，
  所有使用该分类的记录和图表都会统一变化。
- 没有手动指定过的分类，图标按分类名自动派生；本版修复了此前
  「所有自定义分类共用同一个图标」的问题。

### 读盘出错时能真正恢复了

之前存储读取失败时，界面上的「重试保存」按钮点了没有用（要重启应用才行）。
现在读取失败显示的是「**重新读取**」：在外部修好数据文件后点它就能直接恢复，
不用重启。写入失败时仍然显示「重试保存」。防止覆盖损坏原始数据的保护不变。

### 记录行更干净

去掉了和 ⋯ 菜单功能重复的铅笔按钮，编辑器里也去掉了和分类选择器内容重复的
「选择已有标签」下拉。表头不再需要「怎么用」的说明文字。

## 统计口径（与 V1.2 相同）

总计只包括**已经结束**的专注记录，含提前结束时实际专注的部分；进行中的专注、
暂停、休息不计入。跨午夜的记录按实际片段分摊到对应日期。周从周一开始。

删除记录后，今日／周／月统计、图表和菜单栏的今日汇总会立即更新，不需要重启。

## 数据和兼容性

- 继续使用 `sessions.json`，**旧文件无需迁移**即可读取；名称、时长、完成状态不变。
- 本版新增了「分类图标」的存放字段；老文件里没有这个字段也能正常读取，
  读不到的分类一律走自动图标规则。
- 自动化检查：**153 项**领域层测试（计时、存储、旧数据兼容、删除、分类切换、
  Unicode 大小写、统计与日历边界），另有 12 项真实桥接检查、8 项启动事件检查。
  `scripts/test.sh` / `test-bridge.sh` / `test-launch-context.sh`。
- 代码仓库已迁到私有远程，每次推送会自动跑「领域测试 + Release 构建冒烟检查」。

## 本版已知未修的问题（按计划留到后续版本）

- 开启「登录时启动」后，登录时仍会弹出主窗口并抢焦点，且关闭主窗口后 Dock 图标不消失。
  **候选补丁已经写好，需要真人在真实登录场景验收后才会启用。**
- 长时间休息时菜单栏图标仍显示短休息图标（区分长短休息的图标）。
- 菜单栏弹层里的删除入口、以及 VoiceOver 下的分类选择体验，没有完成自动化实测，
  需要人工点一遍。
- 记录数量很大时（几百条以上）图表切换可能有卡顿，暂无实测依据，暂缓优化。
