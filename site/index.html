下载 macOS 版 下载 Windows 版 (.exe) 安装指南

macOS 12.3+ · Windows 10/11 · v3.10.0

首次安装？从这里开始。展开安装指南

  1. 下载对应版本

    macOS 用户推荐下载 DMG；Windows 用户直接下载 Windows 版 ZIP 包（内含直接运行的 .exe 与标准安装程序）。

    下载 macOS ZIP · 4.1 MB · 下载 Windows 产物包 · 14.7 MB

  2. 安装与运行

    macOS：打开 DMG，把应用拖入 Applications 文件夹即可。
    Windows：解压后双击 TomatoBar Personal.exe 即可立即运行，或运行 setup 安装向导。

  3. 首次打开与权限

    两端均采用开源透明构建，数据完全保存在本机。如果 macOS 拦截 ad-hoc 首次打开，请参照下方的安全属性清除命令。

如果 macOS 提示无法打开

确认安装包来自本页的 GitHub 发布链接，并已放入 Applications。在终端执行以下命令后重新打开：

xattr -dr com.apple.quarantine "/Applications/TomatoBar Personal.app"
