首次安装？从这里开始。 展开安装指南

  1. 下载安装包

    选择 DMG 或 ZIP。两个安装包均原生支持 Apple Silicon 与 Intel 架构芯片。

    下载 ZIP · 4.1 MB

  2. 移入 Applications

    打开 DMG 镜像将应用拖入 Applications 文件夹；或将 ZIP 解压后移入 Applications。

  3. 首次打开防拦截

    公开安装包采用 ad-hoc 签名，未付费做 Apple 公证。如 macOS 提示无法打开，请执行下方命令：

如果 macOS 提示「无法打开，因为无法验证开发者」

确认安装包来自本页官方 GitHub 发布链接并已移入 Applications 目录，在 Mac 终端中粘贴执行：

xattr -dr com.apple.quarantine "/Applications/TomatoBar Personal.app"
