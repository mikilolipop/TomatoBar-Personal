下载 macOS 版安装指南

macOS 12.3+ · Apple Silicon / Intel · v3.10.0

首次安装？从这里开始。展开安装指南

  1. 下载

    选择 DMG 或 ZIP。两个安装包均支持 Apple Silicon 与 Intel，无需区分芯片。

    下载 ZIP · 4.1 MB

  2. 移入 Applications

    打开 DMG，把应用拖进 Applications 文件夹；使用 ZIP 时，解压后将应用移入该文件夹。

  3. 首次打开

    公开安装包采用 ad-hoc 签名，未做付费公证。如果 macOS 拦截首次打开，请参照下面的说明。

如果 macOS 提示无法打开

确认安装包来自本页的 GitHub 发布链接，并已放入 Applications。在终端执行以下命令后重新打开：

xattr -dr com.apple.quarantine "/Applications/TomatoBar Personal.app"
